# Daystar Site Factory

A premium website blueprint system, intake automation, and static website generator built with **Astro** and **Tailwind CSS v4**.

This project contains two primary modules:
1. **The Generator App**: A local web dashboard served via Astro SSR. Fill in intake details, customize design tokens, and compile complete websites with one click.
2. **The Starter Template**: A master template featuring modern spacing, responsive design, Schema.org local business structured data, and interchangeable component blocks.

---

## Technical Stack
- **Framework**: Astro (Static for clients, SSR Node adapter for local dashboard)
- **Styling**: Tailwind CSS v4 (configured via CSS custom variables in `@theme`)
- **Forms**: Web3Forms (functional HTML forms, zero-server required)
- **Hosting / Deployments**: Git + GitHub Pages (auto-configured for previews) & Cloudflare Pages (production)

---

## Workflow Guide

### Step 1: Run the Dashboard Generator
Open your shell in the `daystar-site-factory` folder and run:
```bash
npm install
npm run dev
```
Navigate to [http://localhost:4321](http://localhost:4321) in your browser.

### Step 2: Run Claude Intake
1. On the dashboard, fill in the **Business Name**, **Industry**, and **Locations**.
2. Click **"Copy Claude Prompt"** in the sidebar.
3. Paste the prompt into Claude. Claude will act as a conversion strategist and write custom headlines, body copy, service descriptions, and localized content in an easy-to-use structure.

### Step 3: Configure Design & Copy
1. Select the brand colors (Primary, Secondary, Accent, Hover) using the color pickers on the dashboard.
2. Choose the visual styling theme:
   - **Luxury Glassmorphism**: Clean panels, backdrop blurs, subtle glowing blobs.
   - **Clean Split Box**: High-impact text on the left, visual lead funnel on the right.
   - **Industrial Minimal**: Bold typography, spacious margins, conversion focus.
3. Paste the copy generated by Claude into the copywriting sections.

### Step 4: Compile & Launch
1. Click **"Generate Website & Deploy to Git"**.
2. The factory engine will:
   - Create a clean client project folder under `C:\Users\austi\Documents\Websites\<client-slug>`.
   - Copy all Astro starter structures, styles, and assets.
   - Inject the visual tokens and copywriting content.
   - Initialize git, commit all files, create a public GitHub repository, push the code, enable GitHub Pages, and link the home page.
3. Once completed, the dashboard will display the live GitHub Pages URL!

### Step 5: Client Live Launch
For final production launch:
1. Go to your **Cloudflare Pages** or **Vercel** dashboard.
2. Create a new project, select the newly created GitHub repository, and click **Deploy**.
3. Point the client's custom domain to Cloudflare Pages.
