# Daystar Digital AI Site Generation Prompt

Copy and paste the template below into Claude or Antigravity to generate a client website from scratch.

---

```markdown
Please start a new client website project from scratch. Here is the client information:

- Facebook Page: [PASTE FACEBOOK LINK]
- Current Website (if any): [PASTE WEBSITE LINK]
- Google Maps / Reviews: [PASTE GOOGLE MAPS LINK OR RAW REVIEWS TEXT]

Please perform the following steps:
1. Scan these links to extract the Business Name, Phone, Email, Locations served, Story, Services, and Reviews.
2. Formulate a full website blueprint using the "daystar-site-factory" starter template.
3. Choose the appropriate theme preset (use the outlined-button "oak-city" layout for contractors, or "modern-glass" for luxury services). 
4. Recommend a brand color palette based on their profile.
5. Present the summary and ask me any clarifying questions for missing details.
6. Once I approve, run the local generation script, push the code to a new repository on my GitHub account, and help me launch the Cloudflare Pages deploy.
```
